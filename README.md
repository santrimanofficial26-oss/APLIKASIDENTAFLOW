# 🦷 DentaFlow Web App — Vercel Deployment

Repository ini berisi wrapper Web App mandiri berkinerja tinggi untuk mempublikasikan sistem manajemen klinik gigi **DentaFlow** (berbasis Google Apps Script) ke **Vercel** dengan domain kustom atau URL bersih (contoh: `https://dentaflow-app.vercel.app`).

## 📋 Fitur & Keunggulan Wrapper:
- **100% Fullscreen & Responsive:** Menyesuaikan seluruh layar desktop, tablet, maupun smartphone secara presisi (`100vw`, `100vh`).
- **DentaFlow Mint Theme Preloader:** Layar pemuatan halus serasi dengan konsep Fresh Mint & Hygienic Emerald DentaFlow tanpa efek kedip.
- **Iframe Sandboxing Lengkap:** Izin kamera (foto profil/rontgen), unduhan resep/laporan, dialog cetak kwitansi, dan popup WhatsApp berjalan normal.
- **PWA Ready:** Mendukung mode web app mandiri saat disimpan ke layar utama smartphone (iOS / Android).

## 🚀 Cara Deploy ke Vercel (1-Click):

1. Buka dashboard [vercel.com](https://vercel.com) dan login dengan akun GitHub Anda.
2. Klik tombol **Add New...** > **Project**.
3. Pilih repository: `santrimanofficial26-oss/APLIKASIDENTAFLOW`.
4. Klik tombol **Deploy** (Framework Preset biarkan *Other*, Root Directory biarkan *`./`*).
5. Selesai! Web app klinik gigi Anda langsung aktif dengan domain Vercel yang cepat, aman, dan profesional.
